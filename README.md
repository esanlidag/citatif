## Stock Percent Calculator

This repository includes a small Tkinter application for Windows that calculates the price of a stock after various percentage drops. Run `python3 stock_calculator.py` and enter the current stock price. The app will display the price after -5%, -10%, -15%, -20%, -25%, -30%, and -35% changes. You can also enter a custom percentage to see that result.
